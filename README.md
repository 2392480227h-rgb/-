# AI 新手导航 · AI Starter Hub 🧰

一个面向普通用户的 AI 工具导航站，帮助新手按用途发现工具、进入官方页面，并快速完成第一次任务。

## 当前版本

当前收录 **150 个 AI 工具**，覆盖：

- 💬 聊天 / 助手
- 🔎 搜索 / 研究
- ✍️ 写作 / 办公
- 🎨 图片 / 设计
- 🎬 视频 / 音频
- 💻 编程 / 开发
- 🤗 模型 / 开源
- 🖥️ 本地 AI

站点支持搜索、分类筛选、排序、收藏和最近使用记录，工具卡片直接跳转官方站。登录后可进入个人空间查看收藏。

## 教程与 SEO

每个工具都有对应的新手教程数据，并生成独立的 SEO 静态详情页。详情页包含：

- 官方入口
- 新手步骤与第一次提示词
- 教程视频
- 同类工具
- 基础结构化数据与 canonical

教程视频由自动化脚本定期校验，发现明显失效的嵌入地址时会在 GitHub Actions 中报警。

## 自动化

仓库通过 GitHub Actions 维护：

- **GitHub Pages**：部署站点并生成 SEO 静态页
- **AI NOW**：定时刷新公开 AI 动态
- **Tutorial Videos**：整理和校验工具教程视频
- **Video Health Check**：定期只读检查现有视频嵌入和来源页面

数据工作流更新站点数据后，会主动请求 Pages 重新部署，避免数据已经更新但线上页面仍停留在旧版本。

## “免费”怎么标

- **免费入口**：有可直接使用的免费层
- **免费额度**：有免费生成 / 使用额度
- **免费试用**：有限或一次性的免费试用
- **免费 / 开源**：开源、本地运行或社区资源

> AI 产品的免费额度、模型、地区政策和商业使用条款会变化，使用前请以官方页面为准。

## 项目原则

这个仓库的目标很简单：**能白嫖的，尽量给你找出来；不确定是不是免费的，不装作免费。** 🤣

在修改站点前，优先保证现有搜索、收藏、登录和移动端行为不被破坏。
